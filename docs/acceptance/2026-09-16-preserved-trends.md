# Приёмка восстановления графиков

16 сентября 2026. При аудите сохранности параллельной работы найден пробел:
прежние графики остались в `LegacyVietnamDb`, а приложение использует
`CompactVietnamDb`. Исходники сохранились, пользовательский путь — нет.

## Изменение

Карточка выбранной территории снова показывает до шести годовых графиков,
вкладка занятости — до четырёх национальных. Переиспользуются существующие
charts, selectors и общий ComparableTrend из обзора. Территория, источник и
единица ряда фиксированы; конфликт или пропуск года не скрывается за линией.
При нехватке трёх точек остаётся объяснение и исходные наблюдения.

Экспорт Claude в `scripts/pull-vietnam.ts` и generated-снимок не изменялись
этим заданием. Локальная мобильность и новые climate/series/models-контракты
остаются отдельными пунктами интеграции; эта правка их не реализует.

## Проверка

Кодовые команды: `npm test`, `npm run check`, `npx tsc --noEmit`,
`npm run build:local` — пройдены. Они не выполняют pull из БД. Отдельный regression-check
проверяет пропущенный год, отказ от линии без источника/единицы, конфликт,
и рендер именно экспортируемого компактного каталога по живым hash-маршрутам.

Native BrowserUse, скрытая вкладка, localhost:4173:

- `#/vietnam/region/vn`: видны шесть графиков и ссылки источников;
- переход кнопкой «Занятость»: три отраслевых ряда и безработица;
- `#/vietnam/region/vn-lamdong`: недостаточно годовых данных, нет подмены
  рядом старых границ; сырые наблюдения доступны;
- console warn/error: пусто. Playwright не использовался.

Это локальная приёмка. Новая production-выкатка этой правкой не подтверждается.
Следующая публикация выполняется после согласования общего SHA с VIETNOS;
ранее проверенный production-код — `5e76472`.
