## Команды

```bash
npm test
npm run check
npm run build:local
git diff --check
```

`build:local` включает TypeScript и Vite и не вызывает `pull-vietnam.ts`.
Все четыре набора `npm test` прошли: форматирование чисел (11 случаев),
селекторы, граф, календарь. `npm run check`, TypeScript, Vite и
`git diff --check` прошли. Последняя локальная сборка содержит JS 6 185,65 кБ
(gzip 720,15 кБ), CSS 65,65 кБ. Предупреждение Vite о крупном chunk сохранено.
Отдельного настроенного lint-скрипта в репозитории нет. `npm run check`
валидирует данные и старые якоря в исходнике, но сам по себе не доказывает
работоспособность маршрутизации нового интерфейса.

## Ограничения и следующая итерация

- Крупный статический JS bundle остаётся; Vite сообщает о размере chunk. Следующий шаг — ограниченные read-only API и вынесение наборов данных, а не маскировка предупреждения.
- Словарь aliases и provenance рёбер backend пока не доходят до public JSON. В UI не подставляются вымышленные веса/ссылки.
- Географию событий нужно добавить в экспорт. Название локального источника не делает событие национальным; календарь предупреждает о неизвестном охвате.
- Гипотезы редакционные. Сохранение экспериментов, проверка готовности платить и канальная координация ещё не реализованы.
- Generated-файлы, схема БД, зависимости и production не изменялись. План продолжения: `../plans/2026-09-16-data-and-business-roadmap.md`.
