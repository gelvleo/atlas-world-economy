# ATLAS — исследование бизнеса во Вьетнаме

Локальный инструмент для перехода от экономических наблюдений к проверяемым бизнес-гипотезам. Главный охват — весь Вьетнам. Местность рядом с DLI — отдельная площадка для полевой проверки, а не замена национальной картины.

## Рабочее пространство

- **Картина рынка** — национальные показатели, сопоставимые временные ряды и переход к гипотезам.
- **Гипотезы** — плательщик, проблема, доступные подтверждения, неизвестное и критерий эксперимента. Это редакционные предположения, не подтверждённая прибыльность.
- **Регионы** — сравнение одного показателя, периода, единицы и версии границ; пропуски не превращаются в нули.
- **Связи** — поиск участников, рынки, направленные отношения. Совместные упоминания отделены от деловых отношений.
- **Календарь** — события с изменяемым окном, типом и раскрытием источника; даты Вьетнама независимо от часового пояса браузера.
- **Данные** — подробный каталог, поиск и состояние сборов. Локальный срез открывается явно.

Мировая экономика, EdTech и AI-внедрения доступны в «Других атласах». Их валюты, периоды и пересекающиеся выборки не складываются с Вьетнамом.

## Локальный запуск и проверка

```bash
npm ci
npm run dev -- --host 127.0.0.1 --port 4173
npm run check
npm run build:local
```

`build:local` проверяет данные и TypeScript и собирает приложение из закоммиченного снимка, без доступа к БД. Команды проверок новой логики и результаты браузерной приёмки перечислены в `docs/acceptance/2026-09-16-vietnam-workspace.md`.

Playwright запрещён владельцем. UI проверяется через CoDriver либо скрытый native BrowserUse в Codex, без открытия Chrome и без перехвата фокуса. Порядок передачи работы между Codex, Claude и Cursor: `docs/coordination/2026-09-16-handoff.md`.

Историческая команда `npm run build` запускает `pull-vietnam.ts` перед сборкой. При наличии ключей это обновляет локальные generated-файлы. Для воспроизводимой локальной проверки использовать `build:local`. `npm run pull` — отдельное намеренное обновление данных, не часть редизайна.

## Источники и ограничения

- `src/data/vietnam.generated.ts` — выгрузка региональной БД, её дата доступна в `generatedAt`.
- `public/data/vietnam-graph.json` — отдельный снимок графа, загружается при открытии экрана связей.
- `src/data/vietnam.ts` — ранее собранные узлы, потоки и контекст Вьетнама; `nodes.ts` объединяет их с остальными доменами.
- Обновление выполняет `scripts/pull-vietnam.ts`. Ключи остаются на стороне среды сборки и не попадают в клиент.
- Снимок не является live-соединением с БД и не доказывает актуальность каждого источника.
- Массив содержит старые и новые административные границы. Они показываются раздельно. Смена границ не является ростом экономики.
- Одного значения недостаточно для графика тенденции. Разные источники и определения не склеиваются в один ряд.
- OSM/Overture-плотность характеризует разметку и наблюдаемое покрытие; она не измеряет прибыльность или отсутствие конкуренции.
- В старом публичном графе нет provenance каждого ребра. Источник метрики узла не является доказательством всех его связей.
- У текущих событий нет надёжного поля географического охвата. Нельзя считать весь календарь общенациональным.

Backend и схема фактов принадлежат региональному модулю `HERMES_LIFESTYLE_OS`. Atlas не создаёт собственные копии runtime, кронов или системы идентичностей.

## Стек и навигация

React 18, TypeScript, Vite, Recharts, существующая SVG-раскладка графа. Шрифты Geist и Geist Mono поставляются локальными пакетами. Новых runtime-зависимостей для рабочего пространства не требуется.

Сохранён контракт адресов:

```text
#/vietnam/region/<slug>
#/vietnam/market/<region_slug>/<market_slug>
#/vietnam/entity/<slug>
#/vietnam/section/<id>
```

Регион и рынок открывают каталог с нужной сущностью, entity — граф. Исторические section-ссылки продолжают работать; новые экраны используют тот же механизм. Данные и адреса не зависят от сервера маршрутизации.
