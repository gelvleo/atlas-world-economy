# ATLAS — дашборд понимания мировой экономики

Живой интерактивный дашборд для понимания мировой экономики как системы: потоки денег,
цепочки зависимостей, сдвиги спроса на услуги и влияние технологий/ИИ.

> В ATLAS разделены официальные показатели, аналитические оценки, прогнозы и proxy-метрики.
> Рыночные периметры не складываются автоматически: digital health, clinical care,
> wellness, funding и TAM-прокси — разные сущности. Источники открываются из панелей узлов.

## Разделы

1. **🌍 Обзор** — ключевые числа 2026 (мировой ВВП $126.3 трлн, доля услуг 60-65% и т.д.),
   карта всех узлов экономики с фильтрами по типу (страны/сектора/продукты/услуги/технологии),
   анонс четырёх эпох спроса.
2. **💸 Потоки денег** — интерактивная SVG-диаграмма потоков между странами и секторами
   (толщина линии ≈ объём). Фильтр по эпохам, клик по потоку раскрывает описание, клик по узлу —
   карточку со всеми связями.
3. **🔗 Цепочки зависимостей** — 7 сквозных цепочек («чипы → ИИ-дата-центры → энергия»,
   «газ → удобрения → зерно → еда», «медицинские данные → Medical AI → диагностика → care delivery» и др.)
   плюс граф из 16 парных зависимостей с силой связи.
4. **📈 Динамика услуг** — что было популярно в 2010-х, в 2020-х, сейчас и к 2030:
   переключатель эпох, спарклайны спроса по расширенным health/software-вертикалям, дельты и объяснения сдвига.
5. **🤖 Влияние ИИ** — эффекты ИИ (разгон / сжатие / трансформация) с состоянием «сейчас»
   и прогнозом «к 2030», сводные выводы для решений.

## Взаимосвязь и кликабельность

- **Каждый узел** (страна, сектор, продукт, услуга, технология) кликабелен везде: в гриде,
  на диаграмме потоков, в цепочках, в таймлайне и в карточках ИИ. Открывается панель с
  фактами, источниками, потоками, цепочками, динамикой спроса и связанными узлами.
- **Источники и периметр** видны в панели узла: тип (official/analyst/proxy/company/forecast),
  дата, метрика и оговорка о периметре. Ссылка открывается в новой вкладке.
- **Связанные узлы** в панели — переход одним кликом (рекурсивное исследование карты).
- **Перекрёстная навигация**: из панели узла можно прыгнуть в его потоки, цепочки, таймлайн
  или ИИ-эффекты; между разделами — кнопки-переходы внизу каждой секции.
- **Глобальный поиск** по всем узлам в шапке.

## Данные

Ориентиры: мировой ВВП 2026 ~$126.3 трлн; США $32.38 трлн (25.6%); Китай $20.85 трлн (16.5%);
Индия ~6.5% роста; полупроводники ~$1.5 трлн к 2030; capex дата-центров +57% г/г;
NVIDIA ~80-90% рынка AI-GPU; услуги ~60-65% мирового ВВП. Всё помечено как оценки в UI.

Для ключевых новых узлов приведены source-backed значения с указанием периметра:
- **Software / IT Services** — Gartner 2026: Software $1.44 трлн, IT Services $1.87 трлн;
- **AI agents / AI platforms** — Grand View $10.9 млрд, Gartner AI platforms $64 млрд;
- **Digital health** — Grand View $420 млрд (2026); funding US $7.4 млрд (H1 2026, Rock Health);
- **US healthcare** — CMS $5.3 трлн (2024); FDA 1,451 AI/ML-enabled devices;
- **Femtech / Longevity / Mental health** — funding и demographic proxies, не чистые рынки.

Источники и их границы периметра указаны в панели каждого узла.

## Стек и запуск

Vite + React + TypeScript, данные — TS-модули в `src/data/`. Статический билд, готов к Vercel.

```bash
npm install
npm run dev        # разработка: http://localhost:5173
npm run build      # прод-сборка в dist/
npm run preview    # локальный просмотр прод-билда
```

## Деплой на Vercel

Импорт репозитория в Vercel → фреймворк Vite (определяется автоматически) → Deploy.
`vercel.json` с rewrites уже в комплекте. Команда сборки `npm run build`, выход `dist/`.
